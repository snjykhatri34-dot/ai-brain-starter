# Rules for working in this repo

This repo is a personal AI Brain. The files in `brain/` describe its owner.

- Before answering anything about the owner, read `brain/00-index.md`, then whichever linked files are relevant.
- Treat the Brain as the source of truth about the owner's preferences. If a request conflicts with it, point out the conflict and ask.
- Never edit files in `brain/` on your own initiative. Propose changes as a list (file, old text, new text, reason) and wait for approval. Only record facts the owner stated or confirmed.
- Never write secrets into this repo: passwords, API keys, tokens, account or ID numbers, health details.
- Keep each file under 600 words. If one grows past that, propose a split.
- When a change is approved, update the "Last reviewed" date in the file you changed.
